# DSP project for searching template matches in a longer recording

The objective was to develop a practical tool that will allows the user to detect sounds
similar to the selected template within a longer audio recording. From an input in
the form of a WAVE file, the user selects a segment of the audio as the template
and adjusts a few detection settings. The tool provides the user with a graph of
template match factor overtime.
